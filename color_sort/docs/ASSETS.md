# 素材(AI画像)の作り方・納品ルール

画像は別途AIで作る。コードは画像を **ID でのみ**参照し、未配置の間は仮の図形で動く。
必要な素材・サイズ・透過は `assets/art_manifest.json`(台帳)が正。

```
dart run tool/check_assets.dart            # 配置済みの画像を検査(未配置は許容)
dart run tool/check_assets.dart --strict   # リリース前: 必須の未配置も失敗
```

## 画像にしない(コードで描く)もの

- **色の記号・数字**(色覚対応の要)。画像に焼き込むと差し替えで失われる。塗り色もコード側(`palette.dart`)
- **文字全般**(多言語のため)。画像内に文字を入れない。ロゴのみ例外

## AI画像のルール(統一感のため)

1. シリーズ共通の指示文(スタイル・色味・線の太さ)を1つ決め、全素材で使い回す。かわいい・ゆっくり・のどか。
2. 背景は透過PNG(台帳の `transparent: true`)。AIが背景を塗る場合は抜き作業が必要
3. 縁に余白を残す(切れた絵は描画時に不自然になる)
4. 容器は中身(色玉)が見えるよう、手前画像は半透明に
5. 盤面の色玉と競合しないよう、背景は彩度・コントラストを抑える
6. 動物は使わない(競合が多いため)。住人は「こびと」。見た目・数・役割は未決(台帳では仮に3種)
7. 権利: 利用した生成サービスの商用利用規約と、生成物が既存キャラに酷似していないかを確認する

## 未決(素材に影響)

- こびとの見た目・数・役割 / ステージの数 / アプリ名(ロゴ・アイコン)
