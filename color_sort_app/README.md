# color_sort_app

Everpuzz 1本目(色ソート・仮称)の Flutter アプリ。ルール・面生成は `../color_sort`、基盤は別リポジトリの puzzle_core（タグ固定の git 依存）。

## 構成

- `lib/game/game_controller.dart`: 1面のプレイ状態(選択・移動・戻す・やり直し・失敗理由・星)
- `lib/game/app_state.dart`: 同梱60面の読み込み・進行の保存(`puzzle_core` の保存窓口 + SharedPreferences)
- `lib/l10n/strings.dart`: 文言(ja/en)。**画面コードに文言を直書きしない**(テストで検査)
- `lib/ui/`: レベル選択・プレイ画面・容器(色 + 固有の記号 + 数字、鍵/凍結はバッジ)

## 見やすさ(テストで検査)

- 色だけに頼らない(各色に記号と数字)/ 失敗の理由を文で表示 / 星は数でも伝える
- タップ領域 44pt 以上 / 文字 200% で溢れない / 日本語の直書きなし

## ライフ・コイン(puzzle_core の economy を接続)

- ライフ8・15分で1回復(時計は注入。ライフ切れは回復を待つ)。**行き詰まるとライフを1つ失う**(戻す/やり直しの後に詰んだ場合は、やり直しごとに1回)。ライフ0では新しい面を始められない
- コインは1種類。**初回クリア+20、さらに星1つにつき+5(1つ目の星は初回クリアに含む。1面の最大30)**。2回目以降は、星が増えた分だけ+5ずつ(同じ星で繰り返しても増えない)。60面で最小1,200〜最大1,800。確率報酬なし。数値は決定事項 追補4
- 空き容器ブースター(40コイン): 空の容器を1本足す。1回のプレイにつき1回、足した後は戻せない、星は最大2。やり直しても持ち越し
- ヒント(20コイン): 今の盤面から**ソルバーが最短の解の最初の1手**を探し、「ここから／ここへ」を文字とふちどりで示す。別isolateで解くので画面は固まらない。**手が見つからなければ課金しない**(探索してから払う)。次の操作で表示は消える
- リワード広告: `AdGate` を渡したときだけ「広告を見て回復」が出る(未接続なら非表示)
- 数値は `lib/game/app_state.dart` の `economyConfig`(設定データ)。保存は版管理つき

## 計測(puzzle_core の Telemetry)

`level_start` / `level_win`(手数)/ `level_fail`(行き詰まり)/ `booster_used` / `ad_shown` を、`AppState.telemetry` に出す。
実体(analytics 等)は未接続(既定は何もしない)。やり直しで `attempt` が増え、失敗は進行にも試行回数として残る。

## 課金(RevenueCat)

- 商品は `assets/shop/products.json`(広告削除=買い切り、コインパック=消費型)。価格はストアから取得する。
- 公開SDKキーをビルド時に渡したときだけ有効: `flutter run --dart-define=RC_API_KEY=<公開SDKキー>`。キー未設定なら店は出ない(キーはコミットしない)。
- コインは取引IDで重複付与を防ぐ。広告削除はライフの制限も外す。RevenueCat の権利IDは `ads_removed`。

## 町(ホーム)

- 起動すると町。空きマスをタップで置く、建物をタップで育てる/動かす(動かすは移し先のマスをタップ。入れ替え対応)。下の「あそぶ」は次の未クリアの面へ、「面を選ぶ」は面の一覧へ。
- 素材が届くまで建物は図形+名前+段階の文字で代用(`ui/town_screen.dart`)。ライフ0でも町は操作できる。
- 「次のライフは12:30ごろ」のように時刻で示す(「あと◯分」とは言わない)。

### 商品の種類(`assets/shop/products.json`)

| kind | 内容 |
|---|---|
| adsRemoval | 買い切り。広告削除+ライフ制限解除 |
| coinPack / lifeRefill | 消費型(取引IDで重複付与を防ぐ) |
| unlock | 買い切り。`grants`(飾り・スキン・着せ替え・追加面)が使える。復元可 |
| starterPack | 1人1回。コイン+`grants` |

`enabled:false` の商品は、中身の素材・面が揃うまで店に出さない(飾り・スキン・着せ替え・追加面・はじめてセットは現在これ)。ガチャ・確率要素・サブスクは作らない。

### 町の知らせ・贈り物・こびと
- 新しい建物は、町の上部に静かなカードで知らせる(OKで消える。ポップアップで急かさない)。
- 「町の贈り物」は1日1回(端末の日付)。連続しなくても受け取れ、罰はない。
- こびとは合計段階6ごとに1人(最大10人)。画像(`kobito_01〜03`)があれば、町の中のマスの間をゆっくり歩く(8秒歩いて3秒止まる。出発はこびとごとにずらす。タップは通る。「アニメーションを減らす」設定では立ったまま)。画像が無ければ、上部のアイコン表示のまま。歩き方は `ui/town_walk.dart`(時刻と番号だけで決まる純粋な計算)。
- 完成(20種そろう)・満開(全部が最終段階)の知らせは、それぞれ1回だけ。

## 広告(AdMob リワード)
- ライフ切れの案内に「広告を見て回復」を出す(リワードのみ。強制の全画面広告は出さない)。広告削除済みなら出さない。
- 有効化: `--dart-define=ADMOB_REWARDED_ID=<リワード広告ユニットID>`。未指定なら広告ボタンは出ない。
- 初回起動時に同意(UMP)を確認し、同意が得られない地域/状態では広告を出さない。
- アプリID(`AndroidManifest.xml` / `Info.plist`)は**Googleのテスト用ID**が入っている。本番はAdMobで発行したIDに差し替える(差し替えずに公開しない)。
- 実機/エミュレータでの表示確認は未実施(このCI/セッションでは確認できない)。

`town_place` / `town_upgrade` / `town_move`(buildingId, stage, cost, clearedLevels)、`town_gift`、`purchase`(productId)。個人を特定する値は送らない。実体(analytics)は後から差し込む。

## 画像素材の組み込み
- `color_sort/assets/art/<ID>.png` を置くだけで反映される(台帳 `art_manifest.json` のID)。無いIDは図形+文字で代用する。
- 町の建物は `<建物ID>_s1〜s3.png`(マスの下端にそろえて表示)。プレイ画面の背景は `bg_stage_01.png`。
- 容器は `tube_back` / `tube_front` があれば画像で描く(ガラスの内側に色玉の積みが収まる大きさ)。アイコン(`app_icon`)の組み込みは、画像が届いてから別PRで行う。

### 画像素材の組み込み(全点)
建物60・背景5(12面ごとに切り替え。町は今遊ぶ面の段階)・容器(通常/鍵/凍結/そろった時)・こびと3種(町の「こびと n人」を画像で表示)・アイコン。ロゴは未配置(アプリ名の決定後)。
アイコンは `dart run flutter_launcher_icons` で `ios/` `android/` に書き出し済み(元画像 `color_sort/assets/art/app_icon.png`)。Androidのアダプティブアイコン(前景/背景の分離)は未対応。

### 面のテーマ(容器・色玉の画像)
- 12面ごとに背景と同じ段階でテーマが変わる(若草 → 秋 → 冬 → 夏 → 桜)。容器は `tube_back_<テーマ>` / `tube_front_<テーマ>`、色玉は `ball_<テーマ>_<色番号2桁>`(`art_manifest.json` に任意枠)。無ければ共通の `tube_back` / `tube_front`、それも無ければ図形で描く。
- 色玉の画像があっても、**記号と数字は常にコードで描く**(色だけに頼らない)。画像は塗りの代わりになる。

### 季節の資材・飾り(演出だけ。コイン・経済には関係しない)
- 12面ごとに季節が替わる(若草・秋・冬・夏・桜)。季節ごとに資材3つ(`assets/town/buildings.json` の `seasons`)。建物を置く・育てたときに、いまの季節の資材2つを添えたひとことが出る(例「きのこのおうちを栗とれんがで育てました」)。ひとことは下のボタンの上に浮かせ、隠さない。
- 季節を終える(12面クリア)ごとに、季節の飾りが町に1つ贈られる。静かなカード(OKで消える。新しい建物の知らせが先、1度に1枚)と、町の下の「季節の飾り」の帯に並ぶ。画像(`season_<テーマ>`)が無ければ名前の札で代用。
- こびとは、いまの季節の資材(`material_<ID>`)を小さく抱えて歩く(画像があれば)。
- 台帳に任意枠を20点追加(資材15・季節の飾り5)。

### 実機で見つかった不具合の修正(Android・PR #19 の「未確認・気づいた点」)
- ヒントを出すと他の容器が画面の外に出る: 「ここから/ここへ」の文字で容器の幅が広がり、その容器だけ段から押し出されていた。容器の幅を固定して直した。ヒントの文は盤面の下のひとこと欄に出し、スナックバー(下のボタンを隠す)は使わない。
- 画像の容器では下限を小さくして(26)、横に並ぶ本数を増やし、9本でも360x800の盤面領域に収まるようにした。
- 玉の記号と数字の重なり: 記号は左上、数字は右下に寄せ、数字は玉の大きさに合わせて縮める。
- 「面を選ぶ」ボタンは背景の絵の上でも読めるよう、塗りのあるボタンにした。

### Androidのアダプティブアイコン
- 前景(主役+バッジ・透過・中央66%に収める)と背景(グラデーションのみ)を別画像にして、`color_sort/assets/art/app_icon_fg.png` / `app_icon_bg.png` に置く(台帳に任意枠)。
- 置いたら `cd color_sort_app && dart run flutter_launcher_icons -f flutter_launcher_icons-adaptive.yaml` で書き出し、`android/` の差分をコミットする(iOSの `project.pbxproj` に不正な値が入る場合は戻す)。
- それまでは通常のアイコンだけ(新しい端末では枠の中に小さく見えることがある)。

## 標準のメニュー構成(puzzle_core の meta に準拠)
- ホームの上部に **ショップ → 設定 → 情報**(ショップは課金の窓口・商品がそろう時だけ)。構成・文言・設定の保存は puzzle_core の `package:puzzle_core/meta.dart`、画面(`ui/menu.dart`)はこのアプリが持つ。
- 設定: 言語(端末に合わせる/日本語/English。すぐ反映・保存)、動きを減らす(こびとが歩かず立ったまま。端末の設定とどちらかが有効なら止める)、購入の復元(ショップがある時)、データ削除(確認つき。進行・コイン・町を消す。購入した内容・設定は残す)。
- 情報: クレジット(**AI生成画像の表記を含む**)、プライバシーポリシー・利用規約(`--dart-define=PRIVACY_URL=...` / `TERMS_URL=...`。無ければ出さない。**公開前に必ず用意する**)、版(`--dart-define=APP_VERSION=...`)。URLは開く部品を入れていないので、タップでコピーする。

### 遊べる量の調整(面が大量でも)
- 上限(1日◯面など)は設けない。調整はライフ(行き詰まりで減る・勝てば減らない)だけ。
- 町に寄らずに続けて10面クリアすると、クリアの画面に「ひと息ついて、町をながめませんか?」の案内を出す(止めはしない・1回だけ。町に戻るとリセット。計測 `rest_nudge`)。

## ホーム画面ウィジェット(町の絵)
- 町が変わるたび(2秒まとめて)、町の絵(PNG)を作って端末側に渡す(`lib/widget/`、チャンネル `everpuzz/home_widget`)。
- Android: `TownWidgetProvider` が絵を見せ、タップでアプリを開く。ウィジェット一覧に「あなたの町」が出る。**実機未確認**。
- iOS: 設定が要るためソースのみ(`ios/TownWidget/README.md` の手順)。

## エリア(町は章ごとに別)
- 1チャプター=1エリア。町(マス・建物・こびと)はエリアごとに別、コインは共通。町の画面で行き来できる(開いたエリアだけ)。
- 保存: 最初のエリアは従来の `town`、ほかは `town.<パックID>`(移行なし)。進行を初期に戻すと全エリアの町が空になる。
- 背景: `area_village` / `area_meadow` があればそれを、無ければ段階の背景を使う(`TownScreen.areaArt`)。

## 効果音
- `assets/sfx/*.wav`(選ぶ・注ぐ・まちがい・クリア・建物を置く・コイン)。`tool/make_sfx.py` で合成した短いやさしい音。外部の素材は使っていない。
- 設定の「効果音」でオフにできる(`soundOn`、既定はオン)。鳴らせなくても遊びは止まらない。
